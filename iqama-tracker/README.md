# متابعة الإقامات

صفحة ويب + باك اند (Node.js بدون أي مكتبات خارجية) لتسجيل الإقامات ومتابعة تواريخ انتهائها، مع تنبيه لما الإقامة تقرب تنتهي.

## التشغيل

```bash
cd iqama-tracker
npm start          # أو: node server.js
```

افتح المتصفح على http://localhost:3000

يحتاج Node.js الإصدار 18 أو أحدث. البيانات تتحفظ في `data/residencies.json`.

## المميزات

- إضافة / تعديل / حذف إقامة (الاسم، رقم الإقامة، تاريخ الانتهاء، الجنسية، الجوال، جهة العمل، ملاحظات).
- عرض تاريخ الانتهاء بالميلادي والهجري.
- تلوين كل إقامة حسب حالتها: **منتهية** (أحمر)، **قريبة من الانتهاء** (أصفر)، **سارية** (أخضر).
- التنبيهات:
  - شريط تنبيه أعلى الصفحة بكل الإقامات المنتهية أو القريبة من الانتهاء.
  - إشعارات المتصفح (اضغطي "تفعيل إشعارات المتصفح") — إشعار واحد يوميًا لكل إقامة، والصفحة تتحدث كل ساعة.
  - الخادم يطبع التنبيهات في السجل عند التشغيل وكل 24 ساعة.
- تقدري تغيري عدد أيام التنبيه (الافتراضي 30 يوم).
- بحث وفلترة حسب الحالة.

## الـ API

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/residencies` | كل الإقامات مع `daysLeft` و `status` |
| POST | `/api/residencies` | إضافة إقامة |
| GET / PUT / DELETE | `/api/residencies/:id` | عرض / تعديل / حذف |
| GET | `/api/alerts` | الإقامات المنتهية أو القريبة من الانتهاء |
| GET / PUT | `/api/settings` | `{ "alertDays": 30 }` |
