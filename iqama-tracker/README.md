# نظام متابعة الإقامات

نظام ويب لتسجيل إقامات الموظفين ومتابعة تواريخ انتهائها، مع تنبيهات قبل الانتهاء (في الصفحة، وإشعارات المتصفح، وإيميل يومي).
مصمم لقاعدة بيانات كبيرة (مُجرَّب على 200 ألف إقامة، والاستعلامات تأخذ أجزاء من الثانية).

## التقنيات

- **الباك اند:** Node.js 20.12+ و Express 5
- **قاعدة البيانات:** PostgreSQL 13+ (مع إضافة `pg_trgm` للبحث السريع)
- **الإيميل:** Nodemailer (أي SMTP: Office 365 / Gmail / Zoho ...)
- **الواجهة:** HTML + CSS + JavaScript بدون framework، عربي RTL، خط IBM Plex Sans Arabic

## الواجهة

- صفحة دخول بتصميم احترافي وحركات (بطاقات عائمة، خلفية متحركة، حقول بعناوين متحركة، اهتزاز عند الخطأ، انتقال سلس بعد الدخول).
- لوحة متابعة: مؤشرات بعدّاد متحرك، رسم بياني للإقامات المنتهية في الـ 12 شهرًا القادمة، وقائمة الأقرب انتهاءً.
- قائمة جانبية، نوافذ منبثقة للإضافة والتعديل والحذف، وإشعارات منبثقة.
- وضع فاتح وداكن، ومتوافقة مع الجوال، وتحترم إعداد "تقليل الحركة" في الجهاز.

## المميزات

- تسجيل دخول بمستخدمين (كلمات المرور مشفرة بـ scrypt).
- إضافة / تعديل / حذف إقامة، وإدخال تاريخ الانتهاء **بالهجري (أم القرى) أو الميلادي** مع التحويل التلقائي.
- التحقق من رقم الإقامة (10 أرقام يبدأ بـ 2) ويقبل الأرقام العربية ٠-٩، ومنع التكرار.
- بحث بالاسم أو رقم الإقامة أو جهة العمل، وفلترة بالحالة، وترتيب، وتقسيم لصفحات من السيرفر.
- **استيراد CSV** (من Excel) بأعمدة عربية أو إنجليزية، يحدث الموجود ويضيف الجديد ويعرض الأسطر الخاطئة.
- **تصدير CSV** يفتح في Excel بالعربي.
- **التنبيهات:**
  - شريط تنبيه في الصفحة بعدد الإقامات القريبة من الانتهاء (ومنها خلال أسبوع).
  - إشعار متصفح يومي.
  - **إيميل يومي** لقسم الموارد البشرية بقائمة الإقامات اللي ستنتهي + المنتهية خلال آخر 30 يوم.
- عدد أيام التنبيه قابل للتغيير (الافتراضي 30).
- "اليوم" يُحسب بتوقيت السعودية (`Asia/Riyadh`) مهما كان مكان السيرفر.

## التشغيل

```bash
cd iqama-tracker
npm install
cp .env.example .env        # عدلي DATABASE_URL و SESSION_SECRET وإعدادات الإيميل
npm run migrate             # إنشاء الجداول
npm run create-user -- admin 'كلمة-مرور-قوية'
npm start
```

افتحي http://localhost:3000 وسجلي الدخول.

### إنشاء قاعدة البيانات

```bash
sudo -u postgres psql -c "CREATE USER iqama WITH PASSWORD 'CHANGE_ME';"
sudo -u postgres psql -c "CREATE DATABASE iqama OWNER iqama;"
sudo -u postgres psql -d iqama -c "CREATE EXTENSION IF NOT EXISTS pg_trgm;"
```

(الأمر الأخير محتاج صلاحية superuser مرة واحدة فقط.)

## الاستيراد من Excel

احفظي الشيت كـ **CSV UTF-8** وخلي أول صف عناوين. الأعمدة المقبولة:

| العمود | مطلوب | أسماء مقبولة |
|---|---|---|
| الاسم | ✔ | `الاسم` / `name` |
| رقم الإقامة | ✔ | `رقم الإقامة` / `iqama_number` |
| تاريخ الانتهاء | ✔ (واحد منهم) | `تاريخ الانتهاء` (ميلادي YYYY-MM-DD) أو `تاريخ الانتهاء هجري` (مثل 1448-04-22) |
| الجنسية، الجوال، جهة العمل، ملاحظات | | `الجنسية`، `الجوال`، `جهة العمل`، `ملاحظات` |

لو رقم الإقامة موجود قبل كده، بياناته بتتحدث.

## الـ API

كل المسارات (ما عدا الدخول) تحتاج تسجيل دخول.

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/api/login` ، `/api/logout` | الدخول والخروج |
| GET | `/api/residencies?page=&pageSize=&q=&status=&sort=` | القائمة (`status`: expired / expiring / valid) |
| POST | `/api/residencies` | إضافة (`expiryDate` أو `expiryDateHijri`) |
| GET / PUT / DELETE | `/api/residencies/:id` | عرض / تعديل / حذف |
| GET | `/api/stats` | الأعداد حسب الحالة |
| GET | `/api/stats/monthly` | عدد الإقامات المنتهية في كل شهر من الـ 12 شهرًا القادمة |
| GET | `/api/residencies/export.csv` | تصدير (يقبل نفس الفلاتر) |
| POST | `/api/residencies/import` | استيراد CSV (نص الملف في الـ body) |
| GET | `/api/alerts` | الإقامات اللي في التنبيه |
| POST | `/api/alerts/send-email` | إرسال إيميل التنبيه الآن (للتجربة) |
| GET / PUT | `/api/settings` | `{ "alertDays": 30 }` |

## النشر على سيرفر

- شغليه بـ `NODE_ENV=production` و `SESSION_SECRET` عشوائي طويل.
- خليه ورا **HTTPS** (Nginx أو Caddy) لأن الكوكي في الإنتاج `Secure`.
- استخدمي `pm2` أو `systemd` عشان يفضل شغال ويرجع بعد إعادة التشغيل (الإيميل اليومي محتاج السيرفر شغال).
- خدي نسخة احتياطية يومية من قاعدة البيانات: `pg_dump iqama > backup.sql`.
